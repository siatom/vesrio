# ADR-007：编码与换行处理

- 状态：Accepted
- 日期：2026-10-22
- 关联：VES-008、VES-010

## 决策

1. 原生打开仅支持 UTF-8 与 UTF-8 BOM；保留 BOM 状态。
2. 检测到 GBK、UTF-16 等非 UTF-8 编码时返回 `unsupported_encoding`，由用户显式选择「转换并打开」，不静默转码。
3. 转换只改变打开视图的编码解释，不立即写盘；用户保存时才以 UTF-8（按原 BOM 策略）写入。
4. 保存时沿用打开时检测到的 EOL。混合 EOL 文档在首次编辑时按主导 EOL 归一；未编辑保存不写盘，因此不会触发归一。
5. 路径使用规范化绝对路径作为文档身份；打开失败、权限不足、类型不支持均返回稳定错误码。

## 后果

- 旧编码文档需要用户确认后才能编辑；未确认前不会产生任何磁盘修改。
- 混合换行在编辑后会被统一，文档需在首次保存前提示这一行为（见已知问题）。
