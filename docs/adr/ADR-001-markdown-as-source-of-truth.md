# ADR-001：Markdown 文件是正文唯一真源

- 状态：Accepted
- 日期：2026-10-22
- 关联：P-001、ADR-006、VES-010、VES-018

## 背景

写作工具常见的风险是把正文迁入私有数据库或富文本 JSON，导致用户文件被产品锁定；AI 功能又倾向于在正文中注入隐藏标记。Vesrio 的首要承诺是「不丢原文」和「文档独立于产品」。

## 决策

1. 用户打开的 `.md` 文件就是正文真源，应用不维护第二份可写正文。
2. Front Matter、未知 Markdown 扩展、空行和行尾风格按原字节保留；无编辑保存不写盘。
3. 会话、建议、风格卡、快照索引、审计事件存放在应用数据目录的 SQLite 中，不写入 Markdown。
4. 未接受的建议只存在于内存和 SQLite，绝不向用户文件注入私有标记。
5. 快照保存完整文本副本，用于恢复，不改变用户目录结构。

## 后果

- 即使卸载 Vesrio，用户仍可用任意编辑器阅读和修改文档。
- 元数据与正文可能短期不一致（例如建议基于旧版本），因此必须有 revision 与 hash 校验（见 ADR-004）。
- 不能用「把文档转成内部格式再导出」的方式实现编辑功能。

## 验证

- 24 个黄金样本的「打开—不编辑—保存」字节指纹测试：`src-tauri/tests/golden_markdown.rs`。
- 前端拒绝/取消建议后正文逐字节不变：`tests/e2e/editor-ai.spec.ts`。
