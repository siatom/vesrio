# 文屿 Vesrio｜V0.2 跨平台里程碑计划

> 版本：v1.0（Proposed）｜日期：2026-10-22
>
> 里程碑：**V0.2 跨平台（Cross-platform）**
>
> 关联：ADR-010、WBS E7（VES-055～VES-071）、PRD N-06
>
> 状态：待负责人批准。批准前不得据此扩张 V0.1 范围或改动已冻结 ADR。

## 1. 摘要

V0.2 的目标不是增加写作功能，而是让同一套 Vesrio 在 **Windows、macOS、Linux** 上具备一致的数据安全、凭据安全与可用体验：

- 三个平台都能安装、启动、打开/编辑/保存 Markdown；
- 黄金样本在各平台保持字节级无损回环；
- API Key 写入各平台原生凭据库，绝不退化为明文或内存假保存；
- Unix 上的原子保存不弱化 Windows 已有的数据保护；
- 三平台构建、测试、打包、签名与发布有可重复的证据链。

V0.1 的范围与验收保持不变。V0.2 是**独立里程碑**，只做平台化，不把原 PRD 5.5 的写作功能并入本里程碑（见 §9）。

## 2. 平台支持矩阵（建议基线）

| 平台 | 最低版本 | 架构 | 发行物 | 系统 WebView | 凭据后端 | 支持级别 |
| --- | --- | --- | --- | --- | --- | --- |
| Windows | 11 x64；10 22H2 回归 | x64 | NSIS | WebView2 | Windows Credential Manager | 一级（回归基线） |
| macOS | 13 Ventura+ | universal2（arm64 + x86_64） | `.dmg` + `.app` | WKWebView | macOS Keychain | 一级 |
| Ubuntu | 22.04 / 24.04 LTS | x64 | `.deb` + AppImage | WebKitGTK 4.1 | Secret Service（GNOME Keyring / KWallet） | 一级 |
| Fedora | 40+ | x64 | `.rpm`（可选） | WebKitGTK 4.1 | Secret Service | 二级（best effort） |
| Windows ARM64 / Linux ARM64 | — | — | — | — | — | 暂不支持 |
| WSL / 无桌面会话 / 服务器 | — | — | — | — | — | 不支持（无 Secret Service 与 WebView） |
| 移动端 / Web 版 | — | — | — | — | — | 明确非目标 |

说明：

1. **不采用交叉编译发布**。每个平台使用对应原生 runner 构建，避免“能编译但运行时缺库”的假通过。
2. macOS universal2 会增大产物体积与构建时间；若工期紧张，可退化为 arm64 主包 + 独立 x64 包，但需负责人确认并写入支持矩阵。
3. Linux 一级支持以 Ubuntu LTS + GNOME 为基准；X11 与 Wayland 都要验证，其他发行版按“可运行但未承诺”处理。
4. 所有平台共用同一 SQLite schema 与同一 Markdown 行为；平台差异只允许存在于凭据、打包、窗口装饰与快捷键文案等适配层。

## 3. 现状评估与差距

以下结论来自对现有代码、依赖源码与打包配置的静态审查；未在 macOS/Linux 实机执行构建。

| # | 现状 | 影响 | 对应任务 |
| --- | --- | --- | --- |

## 6. 验收门禁

| 门禁 | 条件 | 证据 |
| --- | --- | --- |
| G0 范围冻结 | ADR-010 获批；支持矩阵、非目标、发布物明确；PRD 版本说明同步 | ADR 状态、PRD/WBS 变更记录 |
| G1 可构建 | Windows/macOS/Ubuntu 三平台 CI 编译与单元测试通过 | CI 运行链接与日志 |
| G2 数据安全 | 黄金样本字节回环；Unix 权限保持；冲突/只读/退出保护通过 | `cargo test`、golden 脚本、实机截图 |
| G3 凭据安全 | 三平台“保存 → 重启 → 读取”通过；后端不可用有明确错误；无明文回退 | 测试记录、日志脱敏检查 |
| G4 体验一致 | 快捷键提示、标题栏、菜单、字体、IME 在目标平台可用 | 三平台截图与走查记录 |
| G5 可发行 | macOS 签名公证通过；Linux 干净环境安装运行；Windows 回归通过；产物有校验和 | `spctl`、安装日志、SHA-256 清单 |
| G6 可发布 | G0～G5 全部通过；安全/许可证审计完成；真实用户内测无 P0 | 发布检查单与内测记录 |

**判定规则**：任一平台未在目标系统实机运行，状态只能是 `Not Verified`，不得写“通过”；自动化测试未覆盖的桌面行为必须由人工检查单补足。

## 7. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| macOS 签名/公证证书申请周期长 | 阻塞正式分发 | 在 S5 就发起证书流程；内部测试用未签名构建，但发布门禁必须签名通过 |
| Linux Secret Service 在精简环境缺失 | API Key 无法保存，AI 不可用 | 明确错误提示与文档；不静默退化；是否增加加密文件后端需单独 ADR，不纳入 V0.2 |
| WebKitGTK 版本、Wayland、输入法差异 | 编辑体验或中文输入异常 | 以 Ubuntu 22.04/24.04 双版本、X11/Wayland 双会话验收；IME 列入 VES-068 |
| macOS 无 CDP，桌面 E2E 无法复用 | 自动化证据不足 | Linux 用 WebDriver；macOS 采用脚本化人工检查单 + 浏览器层 E2E；跟踪 `tauri-driver` 的 macOS 支持 |
| Unix 权限/xattr/ACL 语义差异 | 保存后权限变化或元数据丢失 | 以原文件 mode 为准并测试；xattr 采用 best-effort 并文档化；保留快照兜底 |
| CI 成本与时长上升 | 反馈变慢 | 依赖缓存、路径过滤、夜间 E2E；发布构建与 PR 构建分层 |
| 字体回退导致排版漂移 | 阅读/审阅体验不一致 | 明确字体栈与回退顺序；缺字检查；必要时评估可再分发字体 |
| 范围蠕变 | V0.2 变成功能版本 | 本里程碑只做平台化；PRD 5.5 功能顺延 V0.3，需书面确认 |
| Windows 回归被忽视 | 首发平台质量下降 | Windows 保持一级支持；三平台 CI 必须同时绿；VES-068 包含 Windows 回归 |

## 8. 兼容与迁移

1. **数据库**：不新增必要 schema 变更；0.1 的 `user_version` 与迁移脚本保持可升级。若必须变更，按 ADR 要求提供迁移、回滚与兼容测试。
2. **应用数据目录**：使用各平台标准目录（macOS `~/Library/Application Support/com.vesrio.app`、Linux `~/.local/share/com.vesrio.app`）。路径型设置（最近文档、上次文件夹）不跨平台迁移，缺失条目显示为不存在，不自动删除用户文件。
3. **凭据**：沿用 service `com.vesrio.app` / account `provider-default`；Key 不随文档迁移，换机或换 OS 需重新输入，文档中明确说明。
4. **Markdown**：编码、BOM、EOL、未知语法规则不变；同一文件在三平台之间往返不得产生非预期差异。
5. **快照**：仍在应用数据目录；不承诺跨设备同步。跨平台打开同一文档时，以磁盘正文为准，快照仅本机可用。
6. **升级**：同一 OS 上 0.1 → 0.2 原位升级；升级前保留数据库备份；卸载不删除用户 `.md`。

## 9. 与 V0.1 / V0.3 的关系

- **V0.1 不变**：仍按 `docs/wbs.md` 的 Windows 首发范围验收；V0.2 任务不得改变 V0.1 的已通过行为。
- **V0.2 = 跨平台里程碑**：只包含平台化、数据安全对齐、构建/签名/测试/文档。
- **PRD 5.5 的 V0.2 SHOULD 功能**（全文结构检查、术语表、跨文档检索、风格反馈、批量修订、导出）：建议顺延为 **V0.3 功能候选**。这是路线调整，需负责人在批准 ADR-010 时一并确认。
- **启动时机**：VES-055/056/057/058 可在 V0.1 发布前启动，但前提是不改变 Windows 行为且不占用 V0.1 发布门禁；V0.2 正式发布必须在 V0.1 Go 之后。
- **不新增**：云同步、账号、多人协作、移动端、Web 版、App Store 沙盒版仍属于非目标。

## 10. 待确认决策

以下为建议默认值，批准 ADR-010 时逐项确认：

| 决策 | 建议默认 | 备选 |
| --- | --- | --- |
| macOS 最低版本与架构 | macOS 13+，universal2 | 仅 arm64；macOS 12+ |
| Linux 一级支持 | Ubuntu 22.04/24.04 LTS x64，deb + AppImage | 增加 Fedora/rpm 为一级 |

| 原 V0.2 写作功能 | 顺延 V0.3 | 与跨平台并行（不推荐，风险高） |
| Windows 代码签名 | 作为共享发布门禁，证书具备则签 | 继续作为已知问题披露 |

## 11. 计划中的验证命令

以下命令将在对应平台实际执行并记录结果；本文档不预填“通过”。

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm build

cd src-tauri
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test

node scripts/check-golden.mjs
node scripts/check-licenses.mjs
pnpm tauri build
```
