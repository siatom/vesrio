# 文屿 Vesrio 用户指南（V0.1）

> 适用版本：Vesrio 0.1.0 · Windows 11 x64  
> 本指南描述当前实现，不包含未交付的云同步、账号或多 Agent 能力。

## 1. 安装与启动

1. 运行 `Vesrio_0.1.0_x64-setup.exe`。
2. 安装范围为当前用户，不需要管理员权限。
3. 从开始菜单启动「Vesrio」。
4. 首次启动会在 `%APPDATA%\com.vesrio.app` 创建数据库、快照目录与日志目录。

卸载不会删除你的 `.md` 源文件；应用数据目录是否保留由你决定（见第 9 节）。

## 2. 打开与保存

- `Ctrl + O` 打开单个 Markdown 文件。
- `Ctrl + Shift + O` 打开文件夹，左侧显示文件树。
- `Ctrl + N` 新建文稿（选择保存位置）。
- `Ctrl + S` 保存；`Ctrl + Shift + S` 另存为。
- `Ctrl + W` 关闭标签；有未保存修改时会询问「保存并关闭 / 放弃修改」。

保存采用「临时文件 + 原子替换」，失败时原文件保持不变，标签仍保持未保存状态。

### 编码与换行

- 原生支持 UTF-8 与 UTF-8 BOM，并保留 BOM。
- 打开 GBK / UTF-16 等文件时会提示编码不受支持。你可以选择显式转换后打开；Vesrio 不会静默改写文件，只有你保存时才写入 UTF-8。
- 保存沿用原文件的 LF/CRLF。混合换行文档在首次编辑后按主导换行归一；未编辑保存不会写盘。

## 3. 写作界面

| 区域 | 说明 |
| --- | --- |
| 左侧栏 | 工作区文件树、最近文档、项目风格卡入口 |
| 中间 | 编辑器；顶部可切换「源码」与实时预览 |
| 右侧 | 大纲 / Agent / 修订三个标签 |
| 底部 | 字数、字符数、光标位置、写作模式、编码/换行、保存状态 |

- 实时预览隐藏 Markdown 标记；光标所在行会临时显示原始标记，方便精确编辑。
- 「源码」按钮显示完整 Markdown。
- 标题栏左右两端的按钮分别收起 / 展开左侧栏与右侧栏（`Ctrl + B` / `Ctrl + Alt + B`），收起后按钮仍保留在标题栏。
- 标题栏由 Vesrio 自绘：拖动空白处移动窗口，双击空白处最大化 / 还原；右上角是最小化、最大化 / 还原、关闭按钮。
- `Ctrl + Shift + F` 专注模式，`Esc` 退出。
- `Ctrl + Shift + R` 审阅模式。
- `Ctrl + =` / `Ctrl + -` 调整字号。
- `Ctrl + 1 / 2 / 3` 切换大纲 / Agent / 修订。
- `Ctrl + Tab` 在标签间切换。

## 4. 行内 AI 建议

1. 选中一段文字。
2. 在浮动工具栏选择「精简 / 润色 / 改写」，或按 `Ctrl + J` 自定义指令。
3. 在对话框中确认指令、读取范围与候选数量，点击「生成建议」。
4. 若开启「发送前确认外发内容」，检查将发送的文本与字符数，再点「发送给模型」。
5. 建议以浮层卡片显示差异：绿色为新增，红色为删除。原文可展开查看。
6. 点击「接受」才会修改正文；`Ctrl + Z` 可一步撤销。点击「拒绝」或关闭卡片不会改变正文。

### 读取范围与隐私

- `仅选区`：只发送选中文字。
- `选区 + 段落上下文`：额外发送所在段落，帮助模型理解语境。
- `整篇文档`：发送当前文档全文，需你主动选择。

写入范围固定为选区；Agent 对话不能写入正文。

### 过期保护

生成期间如果你继续编辑，旧建议会被标记为「已过期 / 原文在生成期间发生了变化」，无法直接接受。这是为了避免把候选插到错误位置。请重新生成。

### 候选与键盘

- 可一次生成 1～3 个候选，用卡片顶部标签切换；切换不会修改正文。
- 建议卡获得焦点时：`Enter` 接受，`← / →` 切换候选，`Alt + Backspace` 拒绝，`Esc` 关闭或取消生成。

## 5. Agent 对话

1. 打开右侧「Agent」标签。
2. 输入问题，选择读取范围后发送。
3. 回答中的引用可点击，定位到正文对应段落。
4. 会话按文档隔离并持久化；重新打开文档可继续查看历史。

Agent 只读：回答不会自动修改文档，也不会获得文件写入能力。

## 6. 项目风格卡

点击左侧栏底部「项目风格卡」，可编辑：

- 受众、口吻
- 术语表
- 禁用表达
- 补充说明

保存后版本号递增；后续行内建议与 Agent 请求会携带项目风格。优先级为：即时指令 > 项目风格 > 默认风格。

## 7. 修订与快照

- `Ctrl + Shift + M` 或标题栏「创建快照」立即保存当前文本快照。
- 接受 AI 建议前，默认自动创建快照（可在设置中关闭）。
- 右侧「修订」标签列出快照；「恢复」前会再创建一份恢复前安全快照。
- 快照保存在应用数据目录，关闭并重启后仍可恢复。

快照恢复只改变编辑器内容并标记为未保存；按 `Ctrl + S` 才写入磁盘。

## 8. 外部修改与冲突

如果文件在 Vesrio 之外被修改：

- 未保存文档不会被自动覆盖。
- 保存时会提示冲突，可选择重新加载磁盘版本、保留当前内容，或另存为。
- 重新加载前，如开启自动快照，会先保存当前内容。

## 9. 模型配置

打开 `Ctrl + ,` →「模型服务」：

- 默认预设：DeepSeek，Base URL `https://api.deepseek.com`，模型 `deepseek-flash`，最大输出 Token 默认 `384000`（384K）。
- 也可点「OpenAI」切换为 `https://api.openai.com/v1` / `gpt-4o-mini`，或手动填写其它 OpenAI-compatible 地址。
- 模型名称、超时、Temperature、最大输出 Token。
- API Key：在「API Key」密码框粘贴。只写入 Windows 凭据管理器；界面只显示「已安全保存」。
- 保存配置后点「测试连接」，会请求模型列表，验证地址与凭据。

DeepSeek API Key 从 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 获取。API Key 不会进入 SQLite、JSON 配置或日志。删除 Key 后，已保存的其它配置保留。

## 10. 数据位置与恢复

默认应用数据目录：

```text
%APPDATA%\com.vesrio.app\
  vesrio.db          SQLite 元数据
  snapshots\         快照正文
  logs\              脱敏日志
```

恢复建议：

1. 正文丢失或误改：优先在「修订」中恢复快照。
2. 数据库损坏：关闭应用，备份 `vesrio.db` 后重命名它，应用会创建空库；`.md` 正文不受影响。
3. 配置异常：删除数据库中的配置或重新填写模型服务；API Key 需重新输入。
4. 需要彻底清理：卸载后手动删除 `%APPDATA%\com.vesrio.app`。**不要删除你的 `.md` 文件。**

## 11. 已知限制

见 [known-issues.md](./known-issues.md)。重点包括：

- 仅支持 UTF-8/BOM 原生打开，其他编码需显式转换。
- 混合换行首次编辑后会归一。
- V0.1 不提供云同步、多人协作、跨文档 RAG、自动发布。
- 真实模型质量取决于你配置的服务；Mock 后端仅用于开发测试。
