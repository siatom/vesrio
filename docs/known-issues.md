## 2. 功能限制

| ID | 状态 | 限制 | 说明 / 规避 |
| --- | --- | --- | --- |
| F-01 | Open | 仅原生支持 UTF-8 / UTF-8 BOM | GBK、UTF-16 等需显式转换；保存后为 UTF-8。转换前不会写盘 |
| F-02 | Open | 混合换行文档首次编辑后按主导换行归一 | 未编辑保存不会写盘；需要逐字节保真时不要在该文档中编辑 |
| F-03 | Open | 表格在实时预览中仍以文本形式呈现并加样式，不是单元格富文本 | 可正常编辑与保存；不改变 Markdown 结构 |
| F-04 | Open | 快照没有自动清理策略与容量上限 | 长期使用会累积；可手动清理 `%APPDATA%\com.vesrio.app\snapshots` 与对应数据库记录（需先备份） |
| F-05 | Open | 一次只能打开一个主窗口 | 多窗口/多实例不在 V0.1 |
| F-06 | Open | 无自动更新器 | 升级需手动运行新安装包 |
| F-07 | Open | 无崩溃上报/遥测 | 问题排查依赖本地脱敏日志与用户描述 |
| F-08 | Open | 模型服务需兼容 OpenAI Chat Completions / SSE | 非兼容协议需自行加适配器；错误会显示为 `provider_error` |
| F-09 | Open | 无 token 计费/上下文窗口精确估算 | 界面只展示外发字符数；超长文档可能被服务端拒绝 |
| F-10 | Open | 未做完整无障碍审计（屏幕阅读器全流程） | 已有键盘路径与 aria 标签；WCAG AA 仅按设计 token 与对比度自检 |
| F-11 | Open | 风格卡只作用于 AI 请求，不自动改写既有正文 | 这是有意的权限边界 |
| F-12 | Open | Agent 引用依赖生成时的文本片段匹配 | 正文大幅修改后引用可能标记为不可定位；不会错误跳转 |

## 3. 性能观察

- Rust 集成测试实测 10 MB 文档：打开约 **714 ms**，无编辑保存约 **701 ms**（含全文 hash 计算，不写盘）。测试阈值分别为 10 s / 2 s。
- 5 万字文档前端实测：整篇替换 27.8 ms，连续 40 次跳转 38.7 ms（Chrome headless，mock 后端）。这是交互级指标，不等同于真实文风下的主观流畅度；建议实机再用 DevTools Performance 抽查。
- 大文档首次打开会一次性读入内存；V0.1 未实现分块加载。
- 50k 指标来自自动化环境，未覆盖 Windows 11 WebView2；实机走查仍列在发布检查单。

## 4. 明确的非目标（Out of Scope）

- 云同步、账号体系、多人实时协作、移动端。
- 跨文档 RAG、向量数据库、联网检索、自动研究、自动发布。
- 多 Agent 编队、自进化、模型训练。
- 完整 DOCX/WPS 往返、复杂桌面出版。
- 让模型直接写文件、执行命令或调用工具。

## 5. 安全相关提醒

- API Key 只存在 Windows 凭据管理器；更换 Windows 用户或迁移机器后需重新输入。
- 日志默认位于 `%APPDATA%\com.vesrio.app\logs\vesrio.log`，已做键名与密钥形状脱敏，但仍包含文件路径、请求 id 等元数据；分享日志前请自行检查。
- 发送给模型的内容取决于你选择的读取范围；使用第三方模型服务时，请阅读其数据政策。
- 当前安装包未签名，请只从可信来源获取。

## 7. 缺陷分级建议

| 级别 | 定义 | 发布门槛 |
| --- | --- | --- |
| P0 | 正文损坏、静默覆盖、密钥泄露、无法启动/保存 | 必须清零 |
| P1 | 核心旅程阻断（打开、建议、接受、恢复）且无规避 | 必须清零或有批准豁免 |
| P2 | 有规避的功能缺陷、明显体验问题 | 可延后，需记录 |
| P3 | 文案、样式、低频边界 | 可延后 |
